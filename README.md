# Panda Converter

**Powered by Razn**

A modern multilingual file converter for Microsoft Office files.

## Project Structure

```
panda-converter/
  frontend/
    index.html
    config.js
  backend/
    main.py
    requirements.txt
    Dockerfile
  render.yaml
  .gitignore
  README.md
```

## Quick Start

Backend:
    cd backend
    pip install -r requirements.txt
    uvicorn main:app --reload --port 8000

Frontend: open frontend/index.html
